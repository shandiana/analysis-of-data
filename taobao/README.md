# 淘宝用户行为数据分析项目
基于阿里云天池公开数据集，完成电商用户行为全流程数据分析，含数据清洗、指标计算、漏斗分析、用户分层、可视化与业务建议。

## 项目介绍
基于阿里云天池淘宝用户行为公开数据集(地址：https://tianchi.aliyun.com/dataset/649)
使用Python进行数据清洗、指标计算、漏斗分析、用户分层、可视化与业务策略输出。

本项目使用 10 万行抽样数据完成分析，可直接复现。

## 技能栈
Python Pandas | Matplotlib | 漏斗分析 | 用户分层 | RFM | 业务策略建议

## 项目结构
- `TB_10w.ipynb`：完整Python分析代码（含数据清洗、指标计算、可视化）
- `taobao_user_clean_10w.csv`：清洗后的数据集
- `统计图/`：分析过程中生成的可视化图表（漏斗图、活跃时段图等）
- `淘宝用户行为数据分析项目报告.pdf`：完整分析报告与业务建议

## 核心分析内容
1.  用户活跃时段分析：识别午间高峰与晚间补充活跃窗口
2.  行为漏斗分析：定位浏览→意向→购买转化瓶颈
3.  RFM用户分层：划分高价值、潜力、流失用户，制定运营策略
4.  复购率分析：评估用户忠诚度与商品吸引力
