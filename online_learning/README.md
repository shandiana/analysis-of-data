# 在线学习平台用户行为数据分析
基于 Kaggle 公开数据集的全流程数据分析项目，评估平台用户活跃度、学习粘性与流失风险，为精细化运营提供数据支撑。

## 📊 项目简介
本项目针对在线教育平台用户学习行为数据，完成从数据清洗、特征工程、指标计算到可视化分析的全流程工作。通过多维度分析挖掘用户学习规律，定位运营痛点，输出可落地的用户分层运营与内容优化策略。

## 📁 数据来源
- 数据集：Kaggle 公开在线教育用户行为数据集
- 原始数据量：14101 条记录
- 核心字段：用户ID、课程ID、课程类别、经验水平、视频时长、观看时长、跳过次数、暂停次数、脱离度分数、课程完成状态等

## 🔍 核心分析内容
1. **数据清洗与预处理**
   - 关键字段缺失值处理与异常值过滤
   - 新增观看完成率、高脱离度标记等特征
   - 最终保留 12108 条有效数据

2. **核心业务指标分析**
   - 用户活跃度：人均学习课程数、平均学习时长、整体课程完成率
   - 用户粘性：高粘性用户占比（完成1门以上课程且观看完成率>80%）
   - 学习深度：不同课程类别观看完成率对比
   - 功能渗透率：跳过、暂停功能使用率

3. **用户行为与效果关联分析**
   - 分析学习时长、观看完成率、脱离度与课程完成率的相关性
   - 对比不同经验水平用户的学习表现差异

4. **用户分层与流失预警**
   - 划分高粘性、潜力、高风险流失用户群体
   - 输出高风险用户典型画像与课程偏好特征

## 🛠️ 技术栈
- **数据处理**：Python Pandas
- **数据可视化**：Matplotlib、Seaborn
- **开发环境**：Jupyter Notebook

## 🚀 运行说明
1. 克隆仓库到本地
```bash
git clone https://github.com/shandiana/analysis-of-data.git
```
2. 安装依赖
```bash
pip install pandas matplotlib seaborn
```
3. 打开 `test.ipynb` 运行全部代码，即可复现所有分析结果与图表

## 📈 核心成果
- 明确平台核心现状：整体课程完成率 39.45%，高粘性用户占比 6.81%，高风险流失用户占比 9.13%
- 定位关键问题：初学者学习投入不足、中级用户流失风险高、部分课程内容存在冗余
- 输出可落地建议：分阶段任务拆解、高风险用户定向召回、课程内容精简优化等
